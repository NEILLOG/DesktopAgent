# 人工驗測清單

整理日期：2026-10-23。把整個專案「只有人能確認」的項目（真實金鑰、Windows／macOS 實機、GUI 版面、麥克風、公司內網服務）集中在這裡；自動化測試（`dotnet test`、架構測試、Headless 測試）已涵蓋的不列。

## 怎麼填

- 在每列的 **Mac**、**Win** 欄填結果：`✅` 通過、`❌` 失敗（在備註寫現象，或直接回報給我）、`⚠️` 通過但有疑慮（備註寫原因）；留空＝還沒測；`—`＝該平台不需要測。
- 回填方式：直接回到對話，貼 ID 與結果即可，例如：`M14-01 Mac ✅ Win ✅`、`M10-02 Mac ❌ 覆寫卡片沒有顯示行數`。我會依結果修正或更新各計畫與主計畫。
- 建議順序：先 **M14**、**M10**（最新、尚未被任何人試過）→ **M1～M3**（基礎對話與工具，需要金鑰）→ **M5**（人設）→ **M7～M8**（小精靈）→ **M9**、**M12**（歷史與 UI，項目最多）→ **M6**（需要公司內部 Whisper 服務）→ **M0**（光球 POC：主計畫記 Mac／Win 功能項目皆已驗證，只是 README 沒填；真正還沒做的是 M0-07～M0-10 的耗能量測，其餘可依主計畫的紀錄直接補 ✅）。
- 費用提醒：標「需要金鑰」的項目會呼叫真實模型，產生少量費用；請不要把真實金鑰放進截圖。
