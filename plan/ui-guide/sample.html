輕量、清楚、可信任的桌面體驗

本頁是 Lumi 的單頁 Style Guide 與元件 Showcase。主要範例採用鼠尾草綠，並提供五套可由使用者切換的主題。所有主題共用相同元件、尺寸與操作層級。

三項核心原則
  • 一般使用者優先，技術資訊按需要呈現。
  • BYOK 必須清楚顯示供應商、模型與費用歸屬。
  • 溫和但不幼稚，專業但不做成管理控制台。

06

按鈕層級

一個區域最多只有一個主要動作。

AI 說明：Primary 用於完成主要任務；Secondary 用於可逆的輔助操作；Tertiary 用於低優先動作；Danger 僅用於破壞性動作。不要讓「測試連線」和「儲存變更」同時使用 Primary 樣式。

10

給 AI 的生成規則

可直接作為後續 UI 生成 Prompt 的設計上下文。

DESIGN_SYSTEM: Lumi Desktop UI PLATFORM: C# + Avalonia XAML AUDIENCE: 一般非技術使用者 TONE: 輕量、溫和、可信任，避免企業控制台風格 DEFAULT_THEME: sage THEME_IDS: sage | teal | mist-blue | indigo | terracotta THEME TOKENS: - Accent, AccentHover, AccentSoft - TextPrimary, TextSecondary, AppBackground, Border - Switching theme changes color resources only, never layout or component size FIXED SEMANTIC COLORS: - Success #55A981; Warning #D99A3E; Danger #BD5335 LAYOUT: - Page padding 32–48px; section gap 24–32px - Menu width 220–250px; list/detail layout uses 260px + remaining width - Use Grid, Border, StackPanel, ListBox, ItemsControl and ContentControl - No web-only blur, glassmorphism, CSS filters or excessive animation COMPONENTS: - Input height 40px, radius 10px, visible label above input - Card radius 14px, padding 16px, one-level nesting maximum - One primary button per action region - Error states require color + explanatory text - BYOK screens always show provider, exact model name and cost ownership CONTENT: - Prefer plain language such as「AI 連線」「API 金鑰」「預設模型」 - Hide technical fields until needed, but never rename real model names - Captions explain consequences, storage location, cost or disabled state
✓ AI 應產生
可由 Avalonia 控制項直接實作、層級清楚、文字具體的桌面介面。
× AI 不應產生
ChatGPT 仿製頁、三層卡片、滿版漸層、玻璃模糊或只有網頁能做的互動。
Avalonia 主題實作：每套主題建立獨立 ResourceDictionary，View 只引用 ThemeAccentBrush 等語意 Key，不直接寫 HEX。
